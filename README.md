# Yu Climate Networking

A Streamlit + Supabase portal for managing Bay Area environmental/climate-data networking.

## Features
- Dashboard with pipeline metrics
- Today's 3 recommendations
- Manual status updates
- Interaction/reply logging
- Follow-up queue
- CSV exports
- Supabase cloud persistence

## Streamlit secrets
Create these in Streamlit Cloud app settings:

SUPABASE_URL = "..."
SUPABASE_KEY = "..."

Use a publishable/anon key suitable for your Supabase setup. Do not commit secrets to GitHub.
